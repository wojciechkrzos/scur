# Music assets

Current showcase tracks:

- `main_menu_theme.ogg` - **Can't Stop Waiting**, yd, CC0. Source: https://opengameart.org/content/cant-stop-waiting
- `bullet_heaven_theme.ogg` - **ZenoStar**, Centurion_of_war, CC0. Source: https://opengameart.org/content/zenostar
- `bullet_hell_dark_adrenaline.wav` - generated dark adrenaline loop for boss fights.
- `vn_dark_ambient.wav` - original dark VN ambience.
- `vn_mellow_dark.wav` - generated mellow dark VN loop.

Looping tracks can be replaced while keeping the same filenames.

Reserved Bullet Heaven music slots:

- `bullet_heaven_level_up.ogg` - optional level-up selection cue
- `bullet_heaven_victory.ogg` - victory cue
- `bullet_heaven_defeat.ogg` - defeat cue

Missing files are ignored at runtime, so music can be added incrementally.
